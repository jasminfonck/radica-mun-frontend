Proveedor de correo Gmail / Google Workspace Outlook / Microsoft 365 Tipo de cuenta Personal (gmail.com, outlook.com, hotmail.com) Empresarial (Google Workspace / Microsoft 365) Gmail — cómo obtener Client ID y Client Secret:
  1. Vaya a console.cloud.google.com e inicie sesión.
  2. Cree un proyecto nuevo o use uno existente.
  3. En el menú lateral: APIs y servicios → Pantalla de consentimiento OAuth. Elija tipo Externo y complete nombre, correo de soporte y correo del desarrollador. Guarde.
  4. Vaya a APIs y servicios → Credenciales → Crear credencial → ID de cliente OAuth 2.0.
  5. Tipo de aplicación: Aplicación web.
  6. En URIs de redireccionamiento autorizados agregue: {{ 'http://localhost/api/admin/buzon-correo/oauth/callback' }}
  7. Haga clic en Crear. Aparecerán el ID de cliente y el Secreto de cliente. Cópielos.
  8. En Pantalla de consentimiento → Usuarios de prueba, agregue la dirección del buzón.
 Outlook personal — cómo obtener Client ID y Client Secret:
  1. Vaya a portal.azure.com e inicie sesión con la cuenta del buzón o con una cuenta de administrador del mismo tenant al que pertenece el buzón.
  2. En el buscador superior escriba Registros de aplicaciones y haga clic.
  3. Haga clic en Nuevo registro.
  4. Nombre: Radica Mun (o el que prefiera).
  5. En Tipos de cuenta admitidos seleccione: "Cuentas en cualquier directorio de organización y cuentas Microsoft personales".
  6. En URI de redireccionamiento: tipo Web, valor: {{ 'http://localhost/api/admin/buzon-correo/oauth/callback' }}
  7. Haga clic en Registrar. Copie el Id. de aplicación (cliente) — ese es su Client ID.
  8. En el menú de la app: Certificados y secretos → Secretos de cliente → Nuevo secreto de cliente. Describa el secreto y elija el tiempo de vencimiento. Haga clic en Agregar.
  9. Copie inmediatamente el Valor del secreto (solo se muestra una vez).
 Microsoft 365 empresarial — pasos (requiere cuenta de administrador del tenant):
  1. Vaya a portal.azure.com e inicie sesión con la cuenta de administrador.
  2. Busque Registros de aplicaciones → Nuevo registro.
  3. Nombre: Radica Mun. Tipo de cuenta: "Solo cuentas de este directorio de organización".
  4. URI de redireccionamiento: Web → {{ 'http://localhost/api/admin/buzon-correo/oauth/callback' }}
  5. Registre la app. Copie el Id. de aplicación (cliente) (Client ID) y el Id. de directorio (inquilino) (Tenant ID).
  6. En Certificados y secretos → Nuevo secreto. Copie el Valor inmediatamente.
  7. En Permisos de API → Agregar un permiso → APIs que usa mi organización → Office 365 Exchange Online → Permisos delegados → IMAP.AccessAsUser.All. Agregue el permiso.
  8. Haga clic en "Conceder consentimiento de administrador para [su organización]".
